一级/二级品类关系已持久化，品类库扩展到 42 个二级品类；新增冷帽、棒球帽、皮衣、夹克、棉服、休闲裤、西裤、领带和丝巾，一级分类与二级品类都会进入生成提示词。

独立洗护/成分图链路已落地：画布提供独立标签上传、OpenAI/火山方舟视觉识别预填、结构化输入节点与白底 PNG 输出节点，可编辑重渲染，并校验成分总和、重复项和互斥洗护方式。识别结果会显示原始转录与不确定字段，用户必须对照标签确认后才能渲染。

Provider 层已增加 OpenAI Images API、豆包 Seedream/火山方舟和本地 ComfyUI 适配器，并提供桌面端配置界面。API Key 保存在 Windows Credential Manager，非敏感模型/地址/工作流配置保存在运行数据目录；“保存并诊断”可检查密钥、模型、地址、CLI、ComfyUI 工作流及无计费连通性，并明确标记没有发起图片生成。真实账号与本地模型的端到端生图冒烟仍需要用户凭据和工作流后再执行。

本轮已按正式优化顺序补齐安全与评测基础：OpenRouter ICU 的自定义 URL/模型真正传入 CLI；密钥界面显示实际来源；真实 Provider 支持单批张数、用户估价、单批费用和项目剩余预算门禁；恢复迁移会按蒙版能力和限额跳过不兼容任务。自定义人物必须显式确认授权，并可维护最多 7 个角度的身份包。导出会写入逐文件来源和哈希的 AI 内容清单。

固定服饰评测集已建立为 32 例，正负样本各 16 例，并用工作簿媒体部件 SHA-256 锁定。商品真实性 QC 已新增颜色与轮廓自动证据；Logo、文字和扣件保持人工复核。当前环境未配置 OpenAI/火山方舟真实密钥，也未配置 ComfyUI API 工作流，因此三路真实生图冒烟尚未执行，不能标记为通过。

Windows 发行闭环已落地：安装版和便携版都内嵌 FastAPI sidecar、迁移、规则库、MediaPipe QC 模型与前端资源。Electron 会隐藏启动并验证 sidecar 身份，健康后再加载工作台；默认自动选择空闲本地端口，用户数据与日志留在用户目录，退出时回收本应用启动的后端，不再依赖单独安装 Python 或手工启动开发服务。

参考素材质量闭环已完成第一阶段：只读解析 `总览.xlsx` 的 460 个图片位置，区分 179 个正向示例、48 个问题生成结果、43 个缺陷证据、65 个原始对照和 125 个未完成素材；其中 46 个问题结果已与历史平面图库建立本地文件映射。用户上传参考图时会按精确哈希拦截已确认的问题样例，生产参考资产也加入回归检查。

样例审计结论已进一步固化为 `example-calibration-v1` 默认提示词配置：四类输出分别约束结构与扣件、反面臆造、颜色/透明度/厚度漂移、全身图裁切冒充特写、模特身份与姿态等问题。配置明确记录证据来源和数量，工程检查会阻止其与工作簿清单失配；这是可追溯的提示词校准，不冒充模型微调。

结构事实闭环已完成第一版：输入节点可按品类填写版型、领型、袖型、闭合件、口袋、腰头、下摆、图案、标识位置和独特细节；字段会持久化、随项目恢复、进入提示词与缓存键，并在 QC 中生成逐项人工对照清单。系统不会把通用图像相似度伪装成结构语义识别，锁定前必须先点击“满意”确认结构。

首次生成前的提示词选择已补齐：镜头确认页可逐项使用默认提示词或填写自定义补充，选择会持久化并在重开方案后恢复；自定义内容进入最终提示词和缓存键，但不会覆盖商品真实性、结构事实、搭配和模特身份约束。

核心流程已经形成：

```text
准备 -> 生成 -> 审核 -> 导出
```

## 已完成

### 工作台与流程

- 左侧操作台按当前步骤动态切换。
- 左侧操作台支持折叠和鼠标拖拽调整宽度。
- 底部监控台支持折叠和鼠标拖拽调整高度。
- 顶部四步状态条具备实际导航、完成状态和自动推进。
- 支持新手模式与正常模式，并保留首次启动流程引导。
- 画布支持缩放、节点聚焦、图片预览和必要的轻量交互。
- 空素材节点可直接点击上传，已有素材支持替换。
- 点击画布图片可以定位到左侧对应审核操作。

### 准备阶段

- 部位选择、增加、修改和删除。
- 品类选择器只展示已经落地的 42 个二级品类；已移除没有行为的“自定义类型”占位入口，无匹配搜索会明确提示。
- 商品素材上传、替换和删除。
- 素材替换保持原商品/资产绑定，不再产生隐藏重复商品；改类同步数据库并清除旧镜头方案，删除部位会持久化删除商品、关联任务和项目内源文件。
- 商品属性、模特和准备检查清单。
- 商品结构事实按品类筛选、保存与项目恢复。
- 洗护标签独立上传、视觉识别预填、人工确认、确定性图标与文字排版、历史节点恢复及编辑重渲染。

### 生成阶段

- 按输入节点配置生成范围。
- 云端生图任务队列、暂停、恢复、取消和失败重试。
- 上传、提交、云端生成、高清修复、下载、写入等阶段进度。
- 后端事件日志与底部监控台同步。
- 重新打开项目后恢复任务轮询。
- 支持 Mock、OpenRouter ICU、OpenAI Images API、火山方舟 Seedream 和本地 ComfyUI 统一选型。
- Provider 配置支持安全保存 API Key、可配置模型 ID/服务地址和 ComfyUI API 工作流模板。
- Provider 设置显示密钥实际来源、能力矩阵、单批图片上限、用户估价与单批费用上限；OpenRouter ICU 支持自定义模型和 API 根地址。
- Provider 配置支持逐项无计费诊断，区分通过、提醒与失败，并显示是否完成网络检查、是否具备提交条件。
- 额度耗尽、鉴权失败或缺少密钥会自动暂停队列；失败任务显示错误码、中文原因和 Provider 恢复建议，修复前禁止盲目批量重试。选择当前 Provider 后可用“迁移并恢复”保留旧失败版本、创建新版本并迁移剩余排队任务；内容审核类失败不会被误迁移。
- 镜头方案支持首次生成前逐项选择默认提示词或自定义补充，并在提交真实 Provider 前展示和保存。
- 不完整穿搭只在模特特写/整套展示任务中注入真实默认背心或瑜伽短裤；完整套装、连衣裙、平面图和细节图不会误用补位图。
- 镜头确认页会在选中模特类输出时展示实际补位素材缩略图、名称和触发原因；切换为仅平面/细节后自动隐藏，提交前即可核对系统内搭。

### 审核阶段

- 按图片类型和状态筛选。
- 每张图片下直接显示审核操作，支持批量满意和批量锁定。
- 版本历史、提示词历史、版本对比、恢复和 QC 查看。
- 一致性 QC 未通过或尚未完成的生成版本不能锁定或导出；前后端同时执行门禁。
- QC 报告显示结构事实逐项复核清单；只有人工点击满意且自动 QC 通过的版本才能锁定。
- QC 报告单列颜色与轮廓自动证据；Logo、文字和扣件不自动宣称通过，必须人工确认。
- 提示词修正抽屉支持：
  - 按原图重新生成。
  - 按当前生成图进行微调。
  - 局部蒙版重绘。
- 蒙版 PNG 保存并传入 OpenRouter ICU `--mask`。
- 审核列表支持分页和显示更多。
- 参考图导入会拒绝命中问题样例清单的精确文件；原始对照和未完成素材不会被误判为坏图。

### 导出阶段

- 导出设置迁移到左侧操作台。
- 生成图和原图素材可分别选择。
- 支持全选、清空、详细/简洁命名和自定义目录。
- 桌面端原生目录选择与打开导出目录。
- 必拍镜头覆盖检查。
- 导出文件列表支持分页和显示更多。
- 每个导出批次自动写入 AI 内容来源清单，区分生成图与原始素材，并记录 SHA-256、Provider、模型和版本。
