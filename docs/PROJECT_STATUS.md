# LongY Studio 项目进度

更新时间：2026-10-12

## 当前阶段

主流程重构已完成主体功能，当前处于 **阶段 7 初期 / 阶段 7 后续优化准备**。

核心流程已经形成：

```text
准备 -> 生成 -> 审核 -> 导出
```

## 已完成

### 工作台与流程

- 左侧操作台按当前步骤动态切换。
- 左侧操作台支持折叠和鼠标拖拽调整宽度。
- 底部监控台支持折叠和鼠标拖拽调整高度。
- 顶部四步状态条具备实际导航、完成状态和自动推进。
- 支持新手模式与正常模式，并保留首次启动流程引导。
- 画布支持缩放、节点聚焦、图片预览和必要的轻量交互。
- 空素材节点可直接点击上传，已有素材支持替换。
- 点击画布图片可以定位到左侧对应审核操作。

### 准备阶段

- 部位选择、增加、修改和删除。
- 商品素材上传、替换和删除。
- 商品属性、模特和准备检查清单。

### 生成阶段

- 按输入节点配置生成范围。
- 云端生图任务队列、暂停、恢复、取消和失败重试。
- 上传、提交、云端生成、高清修复、下载、写入等阶段进度。
- 后端事件日志与底部监控台同步。
- 重新打开项目后恢复任务轮询。

### 审核阶段

- 按图片类型和状态筛选。
- 每张图片下直接显示审核操作，支持批量满意和批量锁定。
- 版本历史、提示词历史、版本对比、恢复和 QC 查看。
- 提示词修正抽屉支持：
  - 按原图重新生成。
  - 按当前生成图进行微调。
  - 局部蒙版重绘。
- 蒙版 PNG 保存并传入 OpenRouter ICU `--mask`。
- 审核列表支持分页和显示更多。

### 导出阶段

- 导出设置迁移到左侧操作台。
- 生成图和原图素材可分别选择。
- 支持全选、清空、详细/简洁命名和自定义目录。
- 桌面端原生目录选择与打开导出目录。
- 必拍镜头覆盖检查。
- 导出文件列表支持分页和显示更多。
