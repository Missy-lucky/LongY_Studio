# 节点系统设计文档

> 版本：v1.1 | 日期：2026-10-16 | 状态：已确认

## 概述

节点系统替代原有的固定四类 Tab 布局，用户通过拖拽式节点画布完成素材上传、任务规划、生成审核的完整流程。

## 一、节点类型

### 1.1 输入节点（InputNode）

| 属性 | 类型 | 说明 |
|---|---|---|
| categoryId | string | 预设类型 ID（如 'top'） |
| categoryName | string | 显示名（如 '上衣'） |
| categoryGroup | string | 大类（如 '上装'） |
| image | UploadedImage \| null | 上传的素材图，null 为空白 |
| status | 'empty' \| 'uploaded' \| 'confirmed' | 节点状态 |

**行为：**
- 每个节点代表一个穿搭部位，通常只放一张素材图
- 用户可增删、可拖拽、可替换图片、可修改类型
- 空白节点不影响生成，程序自动跳过
- 点击图片区域触发文件上传

### 1.2 模特风格节点（ModelNode）

| 属性 | 类型 | 说明 |
|---|---|---|
| styleId | string | 风格 ID |
| styleName | string | 显示名（如 '通勤简约'） |
| styleGroup | string | 分类（如 '通勤'） |
| locked | boolean | 用户是否已确认 |

**行为：**
- 系统内置模特库，也支持上传项目私有的自定义模特全身图
- 选择风格后自动出现，不需要手动连线
- 可更换、可预览

### 1.2.1 姿势子节点（PoseNode）

- 从模特节点引出，每个项目最多一张。
- 只约束人体动作与构图，不复制参考人物身份、服装或背景。
- 文件归属当前项目，不能被其他项目选用。

### 1.2.2 附加参考节点（ReferenceNode）

- `style`：只约束光线、背景和商业构图，最多两张。
- `detail`：只作为商品局部结构证据，最多三张。
- 参考图内容哈希进入缓存键，替换图片后不会误用旧生成结果。

### 1.3 处理节点（ProcessingNode）

| 属性 | 类型 | 说明 |
|---|---|---|
| processType | 'flat' \| 'detail' \| 'partial' \| 'model' | 处理类型 |
| status | 'idle' \| 'planned' \| 'running' \| 'done' \| 'failed' | 状态 |
| estimatedCount | number | 预计生成张数 |
| estimatedCost | number | 预计成本 |

**四种处理节点：**
1. **平面图生成**：输入各单品素材 → 输出正反面平面图
2. **细节图生成**：输入售卖素材 → 输出细节展示图
3. **模特上身商品特写**（兼容类型 `partial`）：输入售卖素材 + 模特身份 → 重新生成只突出商品区域的高清画面，禁止从全身图截图放大
4. **模特上身搭配展示**（兼容类型 `model`）：输入项目内整套素材 + 模特身份 → 输出完整穿搭；缺失部位按规则注入浅石灰短款露脐运动背心 / 深灰高腰瑜伽短裤实图

### 1.3.1 洗护输入与输出节点（CareInputNode / CareOutputNode）

- 是与四类生图任务并列的独立链路，不进入生成式模型队列。
- 输入品牌、商品名、面料成分、洗护方式和注意事项，可选关联项目内商标/水洗标素材用于溯源。
- 后端强制校验成分合计为 100%，拒绝重复成分和互斥洗护方式。
- 输出固定为 1200 × 1600 白底 PNG；可编辑结构化事实后重新渲染，重开项目会恢复节点。

### 1.4 输出节点（OutputNode）

| 属性 | 类型 | 说明 |
|---|---|---|
| taskCode | string | 任务编号 |
| taskName | string | 任务名 |
| imageType | ProcessType | 图片类型 |
| status | OutputStatus | 状态 |
| version | number | 版本号 |
| parentOutputId | string \| null | 重生成时指向上一版本 |

**状态流转：**
```
queued → generating → pending → satisfied（满意锁定）
                              → unsatisfied → regenerate → 新 output（v+1）
```

## 二、连线规则

| 连线类型 | 颜色 | 允许的连接 |
|---|---|---|
| material（素材线） | #3B82F6 | 输入节点 → 处理节点 |
| model（模特线） | #8B5CF6 | 模特节点 → 上身商品特写/整套搭配处理节点 |
| pose（姿势线） | #EC4899 | 模特节点 → 姿势子节点 |
| reference（参考线） | #14B8A6 | 风格/细节参考节点 → 适用处理节点 |
| care（洗护线） | #D97706 | 洗护输入节点 → 白底说明图输出节点 |
| output（生成线） | #6366F1 | 处理节点 → 输出节点 |
| regen（重生成线） | #F59E0B | 不满意输出 → 新处理节点 |

**约束：**
- 输入节点可连多个处理节点
- 模特节点只能连上身商品特写或整套搭配处理节点
- 处理节点不能互相连接
- 输出节点不能连输入节点

## 三、状态机

### 输入节点
```
empty --上传图片--> uploaded --自动确认--> confirmed
  ↑                                         |
  └-----------删除图片------------------------┘
```

### 处理节点
```
idle --生成方案--> planned --开始生成--> running --完成--> done
                                          |
                                        failed --重试--> running
```

### 输出节点（审核循环）
```
queued → generating → pending
                         ├──满意──→ satisfied（绿色锁定）
                         └──不满意──→ unsatisfied ──重生成──→ 新output(v+1)
```

## 五、输入节点增删逻辑

### 添加流程
1. 点击画布左上角 **[+ 添加部位]** 按钮
2. 弹出类型选择器（底部弹出，带搜索）
3. 按 5 个一级分类分组展示 42 个二级品类
4. 点击类型 → 画布上出现新节点
5. 自动连线到所有已存在的处理节点

### 删除流程
1. 悬停节点 → 右上角出现删除按钮
2. 或右键菜单 → 删除节点
3. 确认后：删除节点 + 删除所有关联连线

### 替换图片
1. 点击已有图片
2. 或悬停 → 点击替换按钮
3. 文件选择器 → 选择新图 → 自动更新

### 修改类型
1. 点击节点类型名称（蓝色）
2. 弹出类型选择器
3. 选择新类型 → 更新节点分类
