# 数据库层
本目录只负责 SQLite 的结构、迁移、种子数据和复杂查询；不存放业务流程代码。
后端通过 `backend/app/database.py` 读取并执行迁移。真实用户图片不在数据库中，数据库只保存相对路径；文件保存在 `storage/`。
## 维护规则
1. 新变更必须新增 `000N__说明.sql`，禁止修改已执行的历史迁移。
2. 表结构必须显式声明约束、外键和索引。
3. 种子数据来自 `asset-library/`，由服务层导入，不在 SQL 中硬编码业务文案。
4. 所有时间使用 UTC ISO-8601 字符串。
5. 迁移在本地 SQLite 连接上启用 `foreign_keys` 后执行。
